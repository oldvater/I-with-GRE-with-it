## 力扣每日一题:
  74.搜索二维矩阵
  [https://leetcode.cn/problems/search-a-2d-matrix?envType=study-plan-v2&envId=top-100-liked]

### 思路：
- 需要定位到具体行，定位完成以后就是行内的二分查找了。定位规则为：小于等于行末尾且大于等于行开头，则认为属于这一行。
  ```python
  class Solution(object):
    def searchMatrix(self, matrix, target):
        """
        :type matrix: List[List[int]]
        :type target: int
        :rtype: bool
        """
        m, n = len(matrix), len(matrix[0])
        left, right = 0, n - 1
        for i in range(m):
            if target <= matrix[i][n - 1]:
                if target >= matrix[i][0]:
                    s = matrix[i]
                    while left <= right:
                        mid = (left + right)/2
                        if s[mid] < target:
                            left = mid + 1
                        else:
                            right = mid - 1
                    ans = s[left]
                    if ans == target:
                        return True
        return False
