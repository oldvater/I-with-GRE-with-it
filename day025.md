## 力扣每日一题:
  208.实现Trie（前缀树）
  [https://leetcode.cn/problems/implement-trie-prefix-tree?envType=study-plan-v2&envId=top-100-liked]

### 思路：
- 数组存储:首先定义存储字典ans和第一个单词相同数组fword，insert就是把word存进字典中，同时更新fword对应首字母的位置
  search就是直接在ans中查找就行，startsWith就是先找到对应fword下标，查找对应下标的fword，里面存储了首字母相同的所有已存储字母，
  遍历fword里的字符和prefix，如果发现前缀相同，则返回True，否则返回False。
  ```python
  class Trie(object):

      def __init__(self):
          self.ans = {}
          self.fword = [[] for _ in range(26)]
        

      def insert(self, word):
          """
          :type word: str
          :rtype: None
          """
          self.ans[word] = word[0]
          k = ord(word[0]) - ord('a')
          self.fword[k].append(word)

      def search(self, word):
          """
          :type word: str
          :rtype: bool
          """
          if word in self.ans:
              return True
          else:
              return False

      def startsWith(self, prefix):
          """
          :type prefix: str
          :rtype: bool
          """
          m = ord(prefix[0]) - ord('a')
          if self.fword[m] is None:
              return False
          l = self.fword[m]
          for word in l:
              k = 0
              if len(word) < len(prefix):
                  continue
              for i, j in enumerate(prefix):
                  if word[i] == j:
                      k += 1
              if k == len(prefix):
                  return True
          return False
- 26叉树:如果只有a,b两种字符，则可以看作2叉数，从左到右遇到a，则进入左子树，b则进入右子树，再将遍历尾端end设置为True，
  表示单词的结束，则对于一个新单词，如果再新单词进行相同规则的遍历后到达了end等于True的区域，则说明新单词被存储过了，
  如果查找时子树不存在，则说明新单词未被存储（因为只有被存储的区域才会有子树），如果end为False则说明存在已新单词为前缀的单词，
  拓展到26个字母同理，只需要构造一个26子树即可。
  ```python
  class Node:
      __slots__ = 'son', 'end'

      def __init__(self):
        self.son = {}
        self.end = False

  class Trie(object):

      def __init__(self):
        self.root = Node()
        

      def insert(self, word):
          """
          :type word: str
          :rtype: None
          """
          cur = self.root
          for c in word:
              if c not in cur.son:
                  cur.son[c] = Node()
              cur = cur.son[c]
          cur.end = True

      def find(self, word):
          cur = self.root
          for c in word:
              if c not in cur.son:
                  return 0
              cur = cur.son[c]
          if cur.end:
              return 2
          else:
              return 1

      def search(self, word):
          """
          :type word: str
          :rtype: bool
          """
          if self.find(word) == 2:
              return True
          else:
              return False

      def startsWith(self, prefix):
          """
          :type prefix: str
          :rtype: bool
          """
          if self.find(prefix):
              return True
          return False
