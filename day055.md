322.零钱兑换
  [https://leetcode.cn/problems/coin-change?envType=study-plan-v2&envId=top-100-liked]

## 思路：
非常标准的完全背包问题，i代表coins数组的下标，j代表需要凑到的数量。不过有点难度的就是不合法的情况，即i<0的情况要
设为inf，而结果输出要为-1，加个判断逻辑即可。
```python
  class Solution(object):
    def coinChange(self, coins, amount):
        """
        :type coins: List[int]
        :type amount: int
        :rtype: int
        """
        n = len(coins)
        cache = [[-1]*(amount+1) for _ in range(n+1)]
        def dfs(i, j):
            if j == 0:
                return 0
            if i < 0:
                return float('inf')
            if cache[i][j] != -1:
                return cache[i][j]
            if j < coins[i]:
                res = dfs(i-1, j)
            else:
                res = min(dfs(i-1, j), dfs(i, j-coins[i]) + 1)
            cache[i][j] = res
            return res
        ans = dfs(n-1, amount)
        return -1 if ans == float('inf') else ans
        
```
