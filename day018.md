## 力扣每日一题:
  105.从前序和中序遍历序列构造二叉树
  [https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal?envType=study-plan-v2&envId=top-100-liked]

### 思路：
- 前序遍历的首节点确定根节点，然后在中序遍历里找到根节点，左边的就是左子树，右边的就是右子树，以此递归，优化可以考虑用字典来降低查询中序遍历的时间复杂度。
  ```python
  class Solution(object):
    def buildTree(self, preorder, inorder):
        """
        :type preorder: List[int]
        :type inorder: List[int]
        :rtype: Optional[TreeNode]
        """
        if not preorder:
            return None
        root_val = preorder[0]
        root = TreeNode()
        root.val = root_val
        for i, x in enumerate(inorder):
            if x == root_val:
                k = i
        # len_l = k
        # n = len(inorder)
        # len_r = n - 1 - k
        root.left = self.buildTree(preorder[1:1 + k], inorder[:k])
        root.right = self.buildTree(preorder[k + 1:], inorder[k + 1:])
        return root
