## 力扣每日一题:
  34.在排序数组中查找元素的第一个和最后一个位置
  [https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array?envType=study-plan-v2&envId=top-100-liked]

### 思路：
- 首先捋清楚二分查找标准函数的作用：找到target对应的位置，如果没有就找到target应该在的位置
  （如果要定位起始位置的话要保证num[mid] = target时更新right，这样left就对应应该在的位置了）
  这样我们就可以找到target和target+1对应的位置s1和s2，而s2 - 1就是target的结尾位置。
  ```python
  class Solution(object):

    def lowerbound(self, nums, target):
        n = len(nums)
        left, right = 0, n - 1
        while left <= right:
            mid = left + (right - left) / 2
            if nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1
        return left

    def searchRange(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: List[int]
        """
        left, right = self.lowerbound(nums, target), self.lowerbound(nums, target + 1) - 1
        if left == len(nums) or nums[left] != target:
            return [-1, -1]
        return [left, right]
