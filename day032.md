## 力扣每日一题:
  131.分割回文串
  [https://leetcode.cn/problems/palindrome-partitioning?envType=study-plan-v2&envId=top-100-liked]

### 思路：
- 回溯问题的有效思路：选或不选：本质上为是否要在两个字母之间进行分割，分割后判断是否为回文串即可，传入start，方便判断。
  ```python
  class Solution(object):
    def partition(self, s):
        """
        :type s: str
        :rtype: List[List[str]]
        """
        ans = []
        n = len(s)
        tmp = []
        def dfs(i, start):
            if i == n:
                ans.append(tmp[:])
                return
            
            if i < n - 1:
                dfs(i + 1, start)
            
            t = s[start: i + 1]
            if t == t[::-1]:
                tmp.append(t)
                dfs(i + 1, i + 1)
                tmp.pop()
        
        dfs(0, 0)
        return ans

- 枚举：枚举分割串的结尾即可，同样记得加入回文串判断。
  ```python
  class Solution(object):
    def partition(self, s):
        """
        :type s: str
        :rtype: List[List[str]]
        """
        ans = []
        n = len(s)
        tmp = []
        def dfs(i):
            if i == n:
                ans.append(tmp[:])
                return
            
            for j in range(i, n):
                t = s[i: j + 1]
                if t == t[::-1]:
                    tmp.append(t)
                    dfs(j + 1)
                    tmp.pop()
        
        dfs(0)
        return ans
