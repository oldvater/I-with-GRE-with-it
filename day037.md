## 力扣每日一题:
  33.搜索旋转排序数组
  [https://leetcode.cn/problems/search-in-rotated-sorted-array?envType=study-plan-v2&envId=top-100-liked]

### 思路：
- 有一说一，我感觉它这个顺序有问题，这题的前置条件**找到旋转点**居然排在这题的后面，有点难绷
  思路：找到旋转点，然后对nums以该点分割成两个有序数组，然后判断一下target在哪个数组里面找就行了
  找旋转点就是将nums[mid]与nums[-1]对比，若大于，则说明mid是大数组里的，旋转点在mid右边，更新left，否则更新right，最后返回right
  （因为是左开右闭，选闭的）。
  ```python
  class Solution(object):

    def findMin(self, nums):
        n = len(nums)
        left, right = -1, n - 1
        while left + 1 < right:
            mid = (left + right)//2
            if nums[mid] > nums[-1]:
                left = mid
            else:
                right = mid
        return right

    def lowerbound(self, nums, left, right, target):
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1
        return left if nums[left] == target else -1
        

    def search(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: int
        """
        n = len(nums)
        i = self.findMin(nums)
        if target > nums[-1]:
            return self.lowerbound(nums, 0, i - 1, target)
        else:
            return self.lowerbound(nums, i, n - 1, target)
