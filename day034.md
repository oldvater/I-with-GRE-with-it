## 力扣每日一题:
  35.搜索插入位置
  [https://leetcode.cn/problems/search-insert-position?envType=study-plan-v2&envId=top-100-liked]

### 思路：
- 简单的二分查找，不过由于可能输入不存在的数，因此返回的条件要修改一下。
  ```python
  class Solution(object):
    def searchInsert(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: int
        """
        n = len(nums)
        left, right = 0, n - 1
        while left <= right:
            mid = (left + right)/2
            if nums[mid] < target:
                left = mid + 1
            elif nums[mid] >= target:
                right = mid - 1
        return left
