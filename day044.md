-  215.数组中的第K个最大元素
  [https://leetcode.cn/problems/kth-largest-element-in-an-array?envType=study-plan-v2&envId=top-100-liked]

**思路**：
利用快速排序，快速定位：快速排序的要点：先随机找出一个下标，对应的值为pivot，同时把该值放到数组最前面防止影响排序，
那么整个数组可以分成两类：<pivot的，>pivot的，小于pivot的应该在左边，大于pivot的应该在右边，所以i,j分别从left+1
(因为left处是pivot)、right开始往中心遍历，直到出现阻塞（i>j,或nums[i]>=pivot,nums[j]<=pivot），
这时候互换nums[i]、nums[j]，又能满足迭代条件继续迭代了，直到i>j，这时候i左边的全是小于等于pivot的数，j右端的全是大于等于pivot的数
由于pivot还在left处，因此需要和小于pivot的下标j互换值，返回此刻的下标j，j左边都小于pivot，j右边都大于pivot，j处等于pivot。
在主函数中执行上述核心算法，然后递归执行j左侧的和j右侧的子数组即可（调整left和right的值即可）。
通过快排直接找到第n-k下标对应的值。
  ```python
  class Solution(object):
    def partition(self, nums, left, right):
        i = randint(left, right)
        pivot = nums[i]
        
        nums[i], nums[left] = nums[left], nums[i]
        i, j = left + 1, right

        while True:
            while i <= j and nums[i] < pivot:
                i += 1

            while i <= j and nums[j] > pivot:
                j -= 1
            
            if i >= j:
                break
            
            nums[i], nums[j] = nums[j], nums[i]
            i += 1
            j -= 1
        
        nums[left], nums[j] = nums[j], nums[left]

        return j

    def findKthLargest(self, nums, k):
        """
        :type nums: List[int]
        :type k: int
        :rtype: int
        """
        n = len(nums)
        target_index = n - k
        left, right = 0, n - 1
        while True:
            i = self.partition(nums, left, right)
            if i == target_index:
                return nums[i]
            if i > target_index:
                right = i - 1
            if i < target_index:
                left = i + 1
```
-  912.排序数组
  [https://leetcode.cn/problems/sort-an-array]

**思路**：
经典的快速排序问题，递归利用快排思想即可。
   ```python
  class Solution(object):
    def sort1(self, nums, left, right):
        i = randint(left, right)
        pivot = nums[i]

        nums[i], nums[left] = nums[left], nums[i]
        i, j = left + 1, right

        while True:
            while i <= j and nums[i] < pivot:
                i += 1
            while i <= j and nums[j] > pivot:
                j -= 1
            if i >= j:
                break
            
            nums[i], nums[j] = nums[j], nums[i]
            i += 1
            j -= 1
        
        nums[left], nums[j] = nums[j], nums[left]
        return j

    def sortArray(self, nums):
        """
        :type nums: List[int]
        :rtype: List[int]
        """
        n = len(nums)
        def quick_sort(left, right):
            orderd = True
            for i in range(left, right):
                if nums[i] > nums[i + 1]:
                    orderd = False
                    break
            if orderd:
                return

            i = self.sort1(nums, left, right)
            quick_sort(left, i - 1)
            quick_sort(i + 1, right)
        
        quick_sort(0, n - 1)
        return nums
```
