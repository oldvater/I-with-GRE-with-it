## 力扣每日一题:
  39.组合总和
  [https://leetcode.cn/problems/combination-sum?envType=study-plan-v2&envId=top-100-liked]

### 思路：
- 由于可以重复选择，因此遍历对象为candidates，同时引入target来记录此时的总和。
  这样，对于每一次递归，就有两个选择：1.加上当前的candidates值，进入下一次递归（记得恢复现场）；2.直接进入下一层递归
  （记得加上递归边界和记录触发条件）。
  ```python
  class Solution(object):
    def combinationSum(self, candidates, target):
        """
        :type candidates: List[int]
        :type target: int
        :rtype: List[List[int]]
        """
        ans = []
        tmp = []
        def dfs(i, left):
            if left == 0:
                ans.append(tmp[:])
                return

            if i == len(candidates) or left < 0:
                return

            dfs(i + 1, left)                 ##数组candidates往后数

            tmp.append(candidates[i])
            dfs(i, left - candidates[i])
            tmp.pop()
        
        dfs(0, target)
        return ans
- 也可以把进入下一层candidates的步骤变成迭代，即对于第i层，查找（i，n-1）就行。
  ```python
  class Solution(object):
    def combinationSum(self, candidates, target):
        """
        :type candidates: List[int]
        :type target: int
        :rtype: List[List[int]]
        """
        candidates.sort()
        ans = []
        tmp = []
        def dfs(i, left):
            if left == 0:
                ans.append(tmp[:])
                return
            
            if i == len(candidates) or left < candidates[i]:      ##由于candidates排过序了，所以如果当前值小于candidates[i],即无法再减时，直接返回，不需要再计算减去之后的情况了
                return
            
            for j in range(i, len(candidates)):
                tmp.append(candidates[j])
                dfs(j, left - candidates[j])
                tmp.pop()
        
        dfs(0, target)
        return ans
